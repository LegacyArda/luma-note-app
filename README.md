## 📌 Özellikler

- **Hızlı ve Akıcı:** Minimum kaynak tüketimi ve anında açılış süresi.
- **Minimalist Arayüz:** Sadece notlarınıza ve üretkenliğinize odaklanan sade tasarım.
- **Yerel Depolama:** Verileriniz tamamen cihazınızda güvende kalır.
- **Kolay Kurulum:** Bağımlılık gerektirmeden taşınabilir (portable) kullanım.

---

## 🛠️ Teknolojiler

- **Çalışma Ortamı:** Electron / Node.js
- **Arayüz:** HTML5, CSS3, JavaScript
- **Paketleyici:** Electron Builder (NSIS Portable)

---

## 🚀 Projeyi Çalıştırma ve EXE Derleme

Kaynak kodları bilgisayarınızda çalıştırmak veya sıfırdan `.exe` kurulum dosyası üretmek için aşağıdaki adımları izleyin:

### 1. Gereksinimler
- Bilgisayarınızda [Node.js](https://nodejs.org/) (LTS sürümü) kurulu olmalıdır.

### 2. Kurulum
Projeyi klonlayın ve gerekli bağımlılıkları yükleyin:

```bash
# Depoyu klonlayın
git clone [https://github.com/LegacyArda/luma-note-app.git](https://github.com/LegacyArda/luma-note-app.git)

# Proje dizinine girin
cd luma-note-app

# Bağımlılıkları kurun
npm install
